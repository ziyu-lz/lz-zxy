# 𝓛𝓩 ꨄ 𝓩𝓧𝓨

一片神秘美丽的星空：正中是一颗由相互纠缠的发光短丝勾勒出边缘的爱心，爱心悬在湖面之上，水面倒映着它。
纯 Canvas 2D 实现，**零依赖、单文件、打开即用**，可直接离线运行。

## 在线访问

https://lz-and-zxy.app.workbuddy.host/

## 本地运行

双击 `index.html` 即可；或起一个静态服务：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 发布到 GitHub Pages

1. 在仓库里上传 `index.html` 和 `README.md` 两个文件：
   `https://github.com/<你的用户名>/<仓库名>/upload/main`
2. 仓库 **Settings → Pages**
3. **Source** 选 `Deploy from a branch`，**Branch** 选 `main` + `/ (root)`，保存
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

> 若仓库名直接叫 `<你的用户名>.github.io`，访问地址就是 `https://<你的用户名>.github.io/`。

## 效果说明

| 元素 | 说明 |
| --- | --- |
| 星云背景 | 多层径向渐变叠加（高空稀薄星云 + 地平线积云 + 水面照亮的薄雾），随时间缓慢呼吸、跟随光标视差浮动 |
| 星空装饰 | 三层景深星点独立闪烁漂移；亮星带**真正的十字星芒**（四根细长尖刺 + 对角副尖）；另有数颗「主角级」大星芒、随机划过的彩色拖尾流星与低透明度尘埃光斑 |
| 爱心边界 | 一圈**三维螺旋光丝**：每根丝（占周长 6%–16%）贴在以心形轮廓为中心线的「圆管」表面，一边沿轮廓前进一边绕管旋转 —— 绕到正面变粗变亮，绕到背面变细变暗，且每根的旋转速度、方向、圈数、层深全随机。每根丝另有两组互不相干的明灭频率，任一瞬间亮着的都不是同一批。空隙里散着少量碎钻、玻璃珠体（部分带细环）与十字星芒，外加两条穿心而过的行星轨道环 |
| 丝间光屑 | 沿轮廓正逆向流动的**长拖尾流星光屑**（拖尾占周长 3%–9%），在厚度方向各占一条车道，高亮持续闪烁并偶发爆闪，头部带亮核 |
| 爱心内部 | 按面积加权均匀铺开的粒子，做低频闪烁与呼吸 |
| 爱心尺寸 | 按「心尖刚好悬在水线上方」反推缩放，峰值心跳时刚好轻触水面 |
| 水面 | 半透明水体 + 横向流动波光 + 会呼吸的水线亮边 + 心尖正下方的光柱 + 触水处的同心涟漪 |
| 倒影 | 与本体**严格一一对应**：底衬按横条镜像错位贴回，光丝 / 光屑 / 星芒逐点镜像，本体的每一点在水下都有且只有一点；整体亮度压到本体四成左右，越深越淡，倒影始终比本体暗 |
| 倒映星河 | 天上较亮的星点逐颗镜像到水下，并随波纹横向抖动 |
| 正中铭文 | `𝓛𝓩 ꨄ 𝓩𝓧𝓨` —— 数学粗花体字母 + Cham 花体爱心。字母本身是一小片星空：深空紫蓝→品红的底色上撒着白色星点（`background-clip: text` 让星点只落在字形内），并随时间缓缓漂移；花体爱心随心跳同步搏动 |
| 心跳 | 「咚—哒」双脉冲缩放，而非简单正弦 |
| 交互 | 移动光标推开粒子；点击产生冲击波，粒子散开后再聚合回心形 |

## 实现要点

- **倒影是严格的一一映射（双射）**：水面映射写成三步 —— 关于水线镜像、按视角做透视压缩、
  沿水平方向叠加波纹位移。公式可逆、点集不增不减，所以本体上每一点（含丝带光屑的头/中/尾端点、
  每颗星芒）在水下都有且只有一点。本体与倒影共用同一份逐帧解算出的状态，对应关系不会随时间漂移。
- **光丝必须逐帧画，进不了离屏图层**：静态图层只能整体调透明度，做不到「这一根暗着、
  那一根亮着」。所以底衬（底光 / 碎钻 / 珠体 / 轨道环）留在离屏图层，光丝改为每帧描边。
- **每根丝的明灭是两组互不相干的随机频率**：慢包络（周期 8–40 秒，带幂指数，有的丝大部分时间
  暗着）决定它在不在场，快闪烁（1.4–6.4 Hz）决定它亮不亮；频率与相位逐根随机，
  所以任何瞬间亮着的都不是同一批丝，永远不会齐闪。
- **三维螺旋的关键不在「绕」，在「深度差」**：光丝沿轮廓前进时绕管旋转
  （法向偏移 R·cosθ、深度 R·sinθ），但真正让它立体的是三件事 ——
  ① 按深度分三层绘制：背面段（z<0）细而暗先画、正面段（z≥0）粗而亮后画、
  正迎面的弧（z≥0.55）再压一道近白的热芯；
  ② 背面的点沿竖直方向微微上抬（模拟略俯视的视角）；
  ③ 丝的管半径放到丝带静态层的 1.5 倍 —— 摆动幅度小了看不出「绕出来再绕回去」，
  再大就散成放射状的针。
- **丝的明灭要留地板**：包络只决定「这一阵有多亮」，不再决定「在不在场」——
  幂指数包络会把大多数丝长时间压到近透明，心形轮廓直接消失。
  亮度地板最终给到 0.45（快闪烁地板 0.38）：光丝永不完全消失，任何瞬间轮廓都在，
  明灭节奏仍然逐根错开。丝芯亮度也要够「深刻」—— `baseA` 下限 0.72、
  正面段 alpha 放到 1.18 倍、线宽 1.38 倍，亮的时候是真亮。
- **本体与倒影的呼吸必须共用同一份时间状态**：每颗粒子的闪烁系数在公共推进处
  （`updateHeart`）算一次存进 `p.twNow`，本体与倒影都读它。
  之前倒影另起了一个固定频率的时间项（`time * 2.1`），
  水面上的爱心和影子的呼吸频率就对不上 —— 凡是「本体一份时间项、倒影一份时间项」的写法，
  频率或相位迟早会岔开；正确的做法永远是**算一次、两处读**。
- **起点用「等分 + 抖动」而不是纯随机**：纯随机会扎堆，留下几段光秃秃的边界；
  等分保证任何瞬间心形轮廓都读得出来，抖动又让它看不出规律。
- **底光必须极淡**：它只负责让边界在任何瞬间都有个可辨认的轮廓。一给亮就把丝与丝之间的
  空隙填死，整条边界又糊回一根白烟管。
- **倒影必须明显比本体暗**：统一由一个系数（0.40）压住，再按入水深度继续衰减。
  之前倒影的所有乘数都在 0.8 上下，加上光柱与水线亮边叠加，水下反而比水上亮 —— 现在全部收敛。
- **星芒必须由细长尖刺构成**：用被压扁的径向渐变去凑星芒，半径一放大就退化成一团模糊光斑。
  改成四根细长三角尖刺（主十字长而细、对角副尖短一半）+ 一枚紧致亮核，才有镜头星芒的味道。
- **倒影压缩系数是算出来的**：镜像后心脏最深处为 `(水线 − 爱心上缘) × squash`，
  取一个刚好不越出屏幕底部的值，保证倒影始终「完整」出现在画面内。六种视口实测均无裁切。
- **爱心位置由几何反推**：把参数方程的包围盒写成常量（宽 32 / 高 29 单位），
  先按「心尖悬在水线上方」定纵坐标，再按可用带宽定缩放 —— 所以爱心能放心放大而不压到水面。
- **内部粒子按面积加权采样**：心形是星形域，内部点可写成 `heartPoint(t) × r`，
  面积元是 `r · |x·y′ − y·x′| · dr · dt`。直接用均匀的 `t` 采样会把粒子全堆到 `x≈0`
  的中轴线上（因为 `x = 16sin³t` 在 `t = 0 / π` 附近变化极慢），心的中央会凭空长出一条竖脊。
  这里按 `|cross|` 建累积分布表反解出均匀的 `t`。
- **光丝的倒影由本体端点逐点镜像**：每根丝这一帧解算出的屏幕端点只解一次，
  倒影直接镜像同一批点，所以水下有几根、水上有几根，一根不多一根不少。
- **拖尾是预烘焙贴图**：按列生成 150×34 的渐变长条（尾部细而透明、头部粗而亮），
  运行时只做一次 `drawImage` + 旋转，不必每帧创建渐变。
- **发光精灵预渲染**：径向渐变每帧创建开销很大，先烘焙成 64×64 贴图，主循环只做 `drawImage`，千级粒子仍能满帧。
- **星云离屏渲染**：以 1/3 分辨率绘制后放大贴回，配合 `globalCompositeOperation = 'lighter'` 得到柔和的加法混色。
- **渲染层次**：天空（底色 → 地平线雾 → 星云 → 尘埃 → 星点 → 流星）→ 水体底色 → 爱心倒影
  （裁剪在水线以下）→ 水面波光/光柱/涟漪 → 爱心本体（核心辉光 → 内部粒子 → 底衬图层 →
  光丝 → 流动光屑 → 镶嵌星芒 → 心尖光爆）→ 光标辉光。
- **自适应**：粒子数、光丝数量、光屑密度随屏幕尺寸/周长变化，DPR 上限 2（底衬图层 1.4），兼顾高分屏清晰度与移动端性能。
- **心跳曲线**：两个不同宽度的高斯脉冲叠加成「咚—哒」，比 `sin` 更有机。
- **铭文位置与字号由脚本下发**：爱心不再居中于屏幕（下方多了水面），
  所以铭文位置改用 CSS 变量 `--names-top` / `--unit` 驱动，无论窗口怎么变、爱心放多大，
  铭文永远钉在心口正中，且始终窄于心宽。
- **无障碍与功耗**：遵循 `prefers-reduced-motion`；页面失焦自动暂停渲染。
- **花体爱心内嵌字体**：`ꨄ`（U+AA04）属于占文（Cham）区段，Windows 默认不装这个字体，
  不处理的话会渲染成豆腐块。这里把 Noto Sans Cham 的最小 woff2 子集以 data URI 内嵌进页面，
  用 `unicode-range: U+AA04` 限定，只有这一个字形参与匹配 —— 约 12KB，依旧离线可用。
- **铭文的垂直对齐是量出来的**：Cham 字形带一条左下卷的尾巴，墨迹重心天然低于字母，
  用 canvas `measureText` 取各字形墨迹上下沿后算出抬升量（约 0.32em），
  最终取 0.20em，让它像带下伸部的字母一样坐在字行中段。
- **兜底探测**：万一某系统连数学花体字母都缺（同样会变豆腐块），
  用 canvas 像素比对探一次，缺字就退回衬线斜体普通字母。
